# Cryptify

🇧🇷 [Portuguese Version](README-PT.md)  | 🇫🇷 [French Version](README-FR.md)

Challenge ONE | JavaScript | Text Decoder

This project was created as a practical exercise in JavaScript and programming logic. It allows encrypting and
decrypting texts with specific rules, interactively showing the final result to the user. It also validates inputs to
avoid invalid characters.

Developed as part of the ONE (Oracle Next Education) program, facilitated by **Oracle** and **Alura**.

## 🧰 Features

- Encrypt messages with specific substitutions:
    - `e` -> `enter`
    - `i` -> `imes`
    - `a` -> `ai`
    - `o` -> `ober`
    - `u` -> `ufat`
- Decrypt encrypted messages.
- Invalid input blocking: accepts only lowercase letters without accents.
- Copy button for the resulting text.
