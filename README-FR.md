# Cryptify

🇧🇷 [Portuguese Version](README-PT.md) | 🇺🇸 [English Version](README.md)

Challenge ONE | JavaScript | Décodeur de Texte

Ce projet a été créé comme un exercice pratique en JavaScript et en logique de programmation. Il permet de crypter et décrypter des textes avec des règles spécifiques, montrant de manière interactive le résultat final à l'utilisateur. Il valide également les entrées pour éviter les caractères non valides.

Développé dans le cadre du programme ONE (Oracle Next Education), facilité par **Oracle** et **Alura**.

## 🧰 Fonctionnalités
- Crypter les messages avec des substitutions spécifiques :
    - `e` -> `enter`
    - `i` -> `imes`
    - `a` -> `ai`
    - `o` -> `ober`
    - `u` -> `ufat`
- Décrypter des messages cryptés.
- Blocage des entrées invalides : accepte uniquement les lettres minuscules et sans accents.
- Bouton pour copier le texte résultant.
