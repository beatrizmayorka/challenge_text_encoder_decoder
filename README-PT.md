# Cryptify

🇺🇸 [English Version](README.md) | 🇫🇷 [French Version](README-FR.md)

Challenge ONE | JavaScript | Decodificador de Texto

Este projeto foi criado como um exercício prático de JavaScript e lógica de programação. Ele permite criptografar e
descriptografar textos com regras específicas, mostrando de forma interativa o resultado final para o usuário. Também
valida entradas para evitar caracteres inválidos.

Desenvolvido como parte do programa ONE (Oracle Next Education), facilitado pela **Oracle** e **Alura**.

## 🧰 Funcionalidades

- Criptografar mensagens com substituições específicas:
    - `e` -> `enter`
    - `i` -> `imes`
    - `a` -> `ai`
    - `o` -> `ober`
    - `u` -> `ufat`
- Descriptografar mensagens criptografadas.
- Bloqueio de entradas inválidas: aceita apenas letras minúsculas e sem acentos.
- Botão de cópia do texto resultante.
